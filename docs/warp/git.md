
git clone (np. git clone URL) - pobranie repozytorium i utworzenie lokalnego katalogu

git status - sprawdzenie gałęzi oraz plików zmienionych i przygotowanych

git add	(np. git add docs/warp/git.md) - dodanie konkretnego pliku do obszaru staging

git commit (np. git commit -m "docs: add Git cheatsheet") - zapis przygotowanych zmian z czytelnym komunikatem

git push (np. git push -u origin feature/git-cheatsheet) - publikacja nowej gałęzi i ustawienie śledzenia

git pull (np. git pull --ff-only origin main) - pobranie zmian bez tworzenia nieoczekiwanego merge commita

git fetch (np. git fetch origin) - pobranie informacji o zmianach bez modyfikowania plików roboczych

git branch - wyświetlenie lokalnych gałęzi i oznaczenie aktywnej

git switch  (np. git switch -c feature/nazwa)- utworzenie gałęzi roboczej i przełączenie na nią

git log	(np. git log --oneline -5) - skrócony podgląd pięciu ostatnich commitów
